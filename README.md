# Leads Generation

منصة عربية أولية لإدارة بيانات الشركات والعملاء المحتملين.

## المزايا الحالية
- لوحة تحكم عربية RTL ومتجاوبة.
- إضافة الشركات يدويًا والبحث والتصفية.
- استيراد CSV وتصدير البيانات بصيغة متوافقة مع Excel.
- تخزين محلي باستخدام SQLite.

## التشغيل على Windows
1. ثبّت Python 3.11 أو أحدث.
2. افتح Terminal داخل المجلد ونفّذ:

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

3. افتح http://127.0.0.1:5000

## النشر
يتضمن المشروع Procfile وrequirements.txt. للنشر العام نحتاج قاعدة بيانات مُدارة مثل PostgreSQL؛ SQLite المحلية ليست مناسبة لاستضافة متعددة النسخ. يمكن استخدام Vercel للواجهة فقط إذا فصلنا الـBackend، أو استضافة Flask على خدمة تدعم Python.

## تنسيق CSV
الأعمدة: company, phone, website, country, city, category, notes. كما يقبل عناوين عربية مثل الشركة والهاتف والدولة والمدينة والنشاط.

## تنبيه
هذه نسخة تأسيسية لإدارة البيانات وليست محرك بحث Google آليًا بعد. إضافة البحث الآلي واستخراج بيانات التواصل ستكون مرحلة مستقلة مع استخدام مصادر وواجهات API مسموح بها.
