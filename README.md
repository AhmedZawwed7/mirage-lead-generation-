# Mirage

منصة Mirage لجمع بيانات الشركات وإدارة العملاء. وحدة البحث الحالية تركز على الشركات في السعودية والإمارات واستخراج وسائل التواصل المهنية المنشورة علنًا.

## المزايا الحالية
- بحث ويب عبر SerpAPI أو Google Programmable Search JSON API.
- زيارة الموقع الرسمي وصفحات التواصل/من نحن لاستخراج أرقام الهاتف والبريد.
- مراعاة robots.txt، تقييد الزيارات لكل موقع، وتجاهل عناوين الشبكات المحلية والخاصة.
- حفظ النتائج ومنع التكرار الأساسي وتصدير CSV.
- إضافة وتعديل وحذف واستيراد وتصدير سجلات الشركات.
- فحص حالة التطبيق عبر المسار `/health`.

## إعداد محرك البحث

### الخيار الموصى به: SerpAPI
1. أنشئ حسابًا لدى SerpAPI واحصل على API Key.
2. ضع المفتاح في متغير البيئة `SERPAPI_KEY`.
3. اضبط `SEARCH_PROVIDER=serpapi`.

### بديل: Google Programmable Search
1. أنشئ Programmable Search Engine واضبطه للبحث في الويب.
2. فعّل Custom Search JSON API في Google Cloud.
3. اضبط `SEARCH_PROVIDER=google_cse`، ثم أضف `GOOGLE_API_KEY` و`GOOGLE_CSE_ID`.

لا تضع مفاتيح API أو كلمات المرور داخل ملفات GitHub. أضفها في Environment Variables لدى خدمة الاستضافة.

## النشر على Vercel
1. اربط مستودع GitHub هذا بمشروع Vercel.
2. اجعل Framework Preset على **Other**، واترك Root Directory كما هو (جذر المستودع).
3. أضف Environment Variables التالية:
   - `SERPAPI_KEY`: مفتاح SerpAPI الفعلي.
   - `SEARCH_PROVIDER`: القيمة `serpapi`.
   - `SECRET_KEY`: قيمة عشوائية طويلة وسرية.
4. ابدأ Deploy، ثم افتح رابط النشر واختبر `/health`. يجب أن يعرض JSON بحالة `ok`.
5. لا تنشر مفاتيح API في المحادثات أو المستودع.

### تنبيه مهم بخصوص قاعدة البيانات
بيئة Vercel Serverless تستخدم حاليًا SQLite داخل `/tmp/leads.db` لتجنب الكتابة إلى مجلد التطبيق غير القابل للكتابة. هذا التخزين **مؤقت وغير دائم**؛ قد تختفي السجلات بين عمليات التشغيل أو عند إعادة التهيئة. لا تستخدم نسخة Vercel الحالية لحفظ بيانات عملاء مهمة قبل ربط قاعدة بيانات دائمة (مثل PostgreSQL مستضافة) وترحيل التطبيق إليها. التشغيل المحلي يحفظ قاعدة البيانات في `leads.db` داخل المشروع.

## التشغيل المحلي على Windows

```powershell
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
python app.py
```

افتح http://127.0.0.1:5000

## الاستخدام
اختر النشاط، الدولة (السعودية أو الإمارات)، والمدينة اختياريًا، ثم ابدأ البحث. النتائج تعتمد على ظهور الموقع في مزود البحث وعلى نشر الشركة لبيانات التواصل في صفحاتها العامة؛ لا يمكن ضمان وجود رقم لكل نتيجة.

## حدود التشغيل
- البحث ينفذ داخل طلب ويب متزامن؛ يوصى بإضافة طابور مهام للبحث الطويل.
- النسخة الحالية لا تحتوي بعد على تسجيل دخول وصلاحيات مستخدمين.
- استخدم البيانات المهنية المنشورة للشركات فقط، والتزم بشروط مزود البحث والقوانين المحلية وسياسات الخصوصية والتسويق المباشر.
- لا يتجاوز المحرك حماية المواقع أو صفحات تسجيل الدخول، ولا يجمع بيانات من صفحات محظورة في robots.txt.


## تسجيل الدخول للمسؤول
- افتح رابط المنصة؛ سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول.
- اسم المستخدم الافتراضي: `Admin`.
- اضبط `ADMIN_PASSWORD` في Environment Variables لدى Vercel (Encrypted/Sensitive)، ولا تضع كلمة المرور في ملفات GitHub.
- جميع صفحات البحث وإدارة الشركات والاستيراد والتصدير تتطلب جلسة مسؤول. الجلسة تنتهي بعد 12 ساعة، وملف تعريف الارتباط محمي بـ HttpOnly وSameSite.
- بعد إضافة أو تغيير متغيرات البيئة، أعد نشر المشروع لتطبيقها.
