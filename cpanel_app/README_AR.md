# Mirage Leads Hunter — cPanel

نسخة الويب المرجعية الكاملة محفوظة ضمن مجلد cpanel_app. تحتوي الحزمة الجاهزة على واجهة البحث العربية والإنجليزية، استخراج الهاتف والبريد، الدفعات، حالات العملاء، تقييم الليدز، Excel/CSV، روابط الخرائط، إرسال SMTP، ومشغل WhatsApp Web المحلي (غير متاح على cPanel المشترك). راجع ملف README_AR.md داخل الحزمة لإعداد Passenger ومتغيرات البيئة والقيود.

ملاحظة: النسخة المنشورة على Vercel منفصلة عن حزمة cPanel؛ لا تستخدم SQLite على Vercel لتخزين بيانات إنتاجية. حزمة cPanel تتطلب Python App/Passenger وتخزينًا دائمًا.
